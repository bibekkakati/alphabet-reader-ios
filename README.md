# Alphabet Reader 🧸

A tiny iOS app I built while learning **SwiftUI and iOS development**.

The idea was deliberately simple: tap a letter, hear it spoken aloud, and make learning the alphabet a little more interactive for kids.

It was one of those projects where the goal wasn't to build a startup or solve a complicated problem — **just learn a new platform by building something from scratch.**

## What I Learned

* Building iOS apps with SwiftUI
* Managing simple app state
* Creating layouts with `LazyVGrid`
* Adding animations and interactions
* Using `AVSpeechSynthesizer` for text-to-speech
* Working with Xcode and iOS project structure

## Tech

* Swift
* SwiftUI
* AVFoundation
